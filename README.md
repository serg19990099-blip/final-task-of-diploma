# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

# Планировщик задач

## Описание

Это итоговый проект по курсу Go.

Приложение представляет собой простой планировщик задач. Можно добавлять задачи, изменять их, удалять, отмечать выполненными, а также создавать повторяющиеся задачи.

Для хранения данных используется база SQLite, а готовый интерфейс находится в папке `web`.

## Что реализовано

- запуск веб-сервера;
- создание базы данных при первом запуске;
- добавление задач;
- просмотр списка задач;
- получение одной задачи;
- редактирование задач;
- удаление задач;
- отметка задачи выполненной;
- повторение задач по правилам:
  - `d N` — через N дней;
  - `y` — каждый год.

## Запуск проекта

Установить зависимости:

```bash
go mod tidy
```

Запустить сервер:

```bash
go run main.go
```

После запуска открыть в браузере:

```
http://localhost:7540
```

При первом запуске автоматически создастся файл `scheduler.db`.

## Запуск тестов

Все тесты:

```bash
go test ./tests
```

Или по отдельности, например:

```bash
go test -run ^TestAddTask$ ./tests
```

## Настройки

При необходимости можно изменить настройки в файле:

```
tests/settings.go
```

По умолчанию используются:

- порт `7540`;
- база данных `scheduler.db`.
